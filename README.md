# Geeklet

Native macOS homage to GeekTool by Hit the Deck Software. Put live shell output, AppleScript results, log tails, images (weather radar, traffic cameras, webcams) and web pages directly on your desktop, with a searchable snippet library so you never have to touch the terminal.

This repository hosts the signed, notarized downloads and the Sparkle update feed. Source is private.

- **Download:** the latest `Geeklet-<version>.dmg` on the [Releases page](https://github.com/markdelfs/geeklet-releases/releases/latest).
- **Requires:** macOS 14 or later, Apple silicon or Intel.
- **Updates:** Geeklet checks for updates automatically; choose **Check for Updates…** to check now. Updates are signed with Sparkle.

The first public release has not been published yet.
